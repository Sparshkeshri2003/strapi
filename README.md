## 🎯 Overview

This project demonstrates a complete **Strapi CMS** setup with modern DevOps practices including:

- ✅ Containerization with Docker & Docker Compose
- ✅ CI/CD pipeline with GitHub Actions
- ✅ Custom content type creation
- ✅ RESTful & GraphQL API auto-generation
- ✅ Comprehensive documentation

## 🚀 Quick Start

### Prerequisites

- Node.js v18+
- Yarn 1.22+ or 4.x
- Docker (optional)
- Git

### Local Development

```bash
# Clone repository
git clone https://github.com/Sparshkeshri2003/strapi.git
cd strapi

# Install dependencies
yarn install

# Build packages
yarn build

# Start development server
cd examples/getstarted
yarn develop
```
